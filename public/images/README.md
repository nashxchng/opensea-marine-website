# Logo Instructions

## Adding the Opensea Marine Services Logo

1. Place your logo file in this directory (`public/images/`)
2. Name it `logo.png` (or update the path in Navbar.tsx and Footer.tsx)
3. Recommended dimensions:
   - Width: 200-300px
   - Height: 60-80px
   - Format: PNG with transparent background (preferred) or with black background
   - File size: Optimize to under 100KB for web performance

## Current Logo Path

The logo is referenced as `/images/logo.png` in:
- `components/Navbar.tsx`
- `components/Footer.tsx`

If your logo file has a different name, update the `src` attribute in both components.

## Logo Specifications

Based on the design:
- Logo contains "OPENSEA" in large text
- "MARINE SERVICES" below in smaller text
- Stylized wave graphics with blue gradient
- Black background

The logo will automatically scale and maintain aspect ratio on the website.
